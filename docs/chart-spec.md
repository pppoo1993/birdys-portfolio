# 项目详情图表展示规范

> 基于「吃鲸AI」与「爱奇艺明星陪看直播间」两个项目的图表提炼。
> 版本：v1.0 | 最后更新：2026-06-12

---

## 一、总体布局

| 规则 | 值 | 适用范围 |
|------|-----|----------|
| 图表整体居中 | `max-width` + `margin: 0 auto` | 全部图表 |
| 窄图容器 | `max-width: 660px` | 3 列手机截图流 |
| 宽图容器 | `max-width: 900px` → `max-width: 600px`（控制截图高度一页内） | 3 列含正文卡片 |
| 全局视界容器 | `max-width: 950px` | 多层级架构图 |
| 图表内元素对齐 | `align-items: center` | 截图 + 名称 + 描述居中 |
| 一页内展示 | 通过容器 `max-width` 间接控制截图高度（见下方原理） | 全部手机截图图表 |
| 比例保证 | **只用 `width:100%` + `aspect-ratio`，禁止同时写 `max-height`** | 全部截图 |

---

## 二、手机截图占位

| 属性 | 规范值 |
|------|--------|
| 比例 | `aspect-ratio: 1 / 2.168`（iPhone Pro 393×852） |
| 宽度 | `width: 100%`（填满所在列）。例外：双列固定宽布局可用 `width: 180px` |
| 高度控制 | **不设 max-height**，通过容器 `max-width` 间接控制。公式：截图高度 ≈ 列宽 × 2.168 |
| 圆角 | `border-radius: 4px` |
| 边框 | `1px solid #222226` |
| 背景 | `linear-gradient(135deg, #141416 0%, #1A1A1A 100%)` |
| 光晕 | `::before` 径向渐变 `rgba(199,255,0,0.03)` |

## 三、截图间箭头

| 属性 | 规范值 | 参考来源 |
|------|--------|----------|
| 字号 | `16px` | 全局视界 |
| 颜色 | `#A0A0A0` | 全局视界 |
| 水平内边距 | `padding: 0 6px` | 全局视界 |
| 与截图 gap | `gap: 28px`（flex 容器） | 全局视界 |
| 垂直对齐 | 父容器 `align-items: flex-start`；箭头 `margin-top` = 截图高度/2 - 8px（与截图垂直中心精确对齐） | 铁律 |
| 不伸缩 | `flex-shrink: 0` | — |
| 移动端 | `transform: rotate(90deg); margin-top: 0` | 竖排时旋转并重置 margin |

## 八、响应式断点

| 断点 | 行为 |
|------|------|
